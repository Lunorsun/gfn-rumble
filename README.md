# GFN Rumble (GFN 진동) — 아이패드용 지포스 나우 진동 앱

아이패드에서 지포스 나우를 열고, 게임이 보내는 진동 신호를 컨트롤러로 전달해 주는 앱입니다.
App Store를 거치지 않고, 본인 Apple ID로 직접 설치합니다.

> **먼저 알아두세요**
> - 이 앱은 아직 **실제 아이패드에서 시험해 보지 못했습니다.** (Windows에서는 iOS 앱을 실행할 수 없어요.) 처음 설치하면 5단계의 진동 테스트로 확인해 주세요.
> - PC는 **처음 한 번만** 필요합니다. 그 뒤 갱신은 아이패드 혼자 합니다.
> - 아이패드에서 **개발자 모드**를 켜야 합니다. (탈옥이 아니고, 직접 만든 앱 실행을 허용하는 설정입니다.)

---

## 준비물

| 준비물 | 설명 |
|---|---|
| Windows PC (64비트) | 처음 설치할 때 한 번만 사용 |
| USB 케이블 | 아이패드와 PC 연결용 |
| 아이패드 | 암호(잠금 비밀번호)가 설정돼 있어야 함 |
| Apple ID | 아이패드에 로그인된 계정이 아니어도 됩니다 |
| GitHub 계정 | 앱 파일을 만드는 데 사용 (무료) |
| Wi-Fi | 설치와 갱신에 필요 |

**App Store 앱 1개가 필요합니다:** `LocalDevVPN` (무료).
가족 공유의 '구입 요청'이 무료 앱에도 걸려 있으면 이 앱 하나는 승인을 받아야 합니다.

## 1단계: 앱 파일(.ipa) 만들기 — GitHub

Windows에서는 iOS 앱을 만들 수 없어서, GitHub의 무료 맥 서버가 대신 만들어 줍니다.

1. [github.com/new](https://github.com/new) 에서 새 저장소를 만듭니다.
   - 이름: 아무거나 (예: `gfn-rumble`)
   - **Public** 추천: 빌드가 무제한 무료이고, 아이패드에서 바로 내려받을 수 있습니다. 코드에 개인정보는 없습니다.
2. 저장소 화면에서 **uploading an existing file** 링크를 누릅니다.
3. 이 폴더 **안에 있는 것들**을 전부 끌어다 놓습니다. (폴더 자체가 아니라 안의 내용물)
   - `.github` 폴더
   - `GFNRumble` 폴더
   - `project.yml`
   - `README.md`
4. **Commit changes** 를 누릅니다.
5. 저장소에 `.github/workflows/build.yml` 파일이 보이는지 확인합니다.
   - 안 보이면: **Add file → Create new file** → 이름 칸에 `.github/workflows/build.yml` 입력 → PC에 있는 같은 파일 내용을 붙여넣고 커밋.
6. 위쪽 **Actions** 탭으로 가면 `Build IPA`가 자동으로 돌고 있습니다. 5분쯤 기다립니다.
   - 초록색 체크 ✅: 성공. 저장소 첫 화면 오른쪽의 **Releases** 에 `GFNRumble.ipa` 가 생깁니다.
   - 빨간색 ✗: 실패. 실패한 항목을 눌러 나오는 오류 내용을 복사해서 Claude에게 보여주세요.

## 2단계: SideStore 설치 — PC에서 한 번만

SideStore는 아이패드에서 앱을 직접 설치하고 갱신해 주는 도구입니다.
아래는 [SideStore 공식 문서](https://docs.sidestore.io/docs/installation/prerequisites) 순서입니다.

**아이패드에서**

1. App Store에서 [LocalDevVPN](https://apps.apple.com/app/localdevvpn/id6755608044) 을 설치합니다.
2. LocalDevVPN을 열고 **Connect** 를 누릅니다. "VPN 구성 허용"이 뜨면 허용합니다.
   - 이 VPN은 인터넷을 다른 곳으로 보내지 않고, 아이패드가 자기 자신과 통신하게 해 주는 용도입니다.

**PC에서**

3. Microsoft Store에서 **Apple 기기**(Apple Devices) 앱을 설치하고 **한 번 열어서 사용권 계약에 동의**합니다.
   - 동의하기 전에는 아이패드 연결 서비스가 켜지지 않아, iloader에 `Failed to connect to usbmuxd` 오류가 납니다.
   - Apple 기기 앱 대신 [iTunes](https://www.apple.com/itunes/download/win64)를 써도 됩니다.
4. [iloader](https://github.com/nab138/iloader/releases/latest/download/iloader-windows-x64.msi) 를 내려받아 설치합니다.
5. 아이패드를 USB로 연결하고, 아이패드에 "이 컴퓨터를 신뢰하겠습니까?"가 뜨면 **신뢰** 를 누릅니다.
6. iloader를 열고 Apple ID로 로그인합니다.
7. '기기' 칸의 아이패드에 **선택됨** 표시가 있는지 확인하고, **SideStore (안정)** 을 누릅니다.
   - 선택됨 표시가 없으면 설치 버튼이 반응하지 않습니다. **새로고침** 을 누르거나 케이블을 다시 연결하세요.

**다시 아이패드에서**

8. **설정 → 일반 → VPN 및 기기 관리** → '개발자 앱' 아래의 본인 Apple ID → **신뢰**.
   - iPadOS 18 이상에서는 **허용 및 재시동** 을 선택합니다.
9. **설정 → 개인정보 보호 및 보안** → 맨 아래 **개발자 모드** 를 켭니다. 아이패드가 다시 시작됩니다.
10. LocalDevVPN을 열어 **Connect**.
11. SideStore를 열고, iloader에서 쓴 것과 같은 Apple ID로 로그인합니다.
12. **My Apps** 탭에서 SideStore 옆의 **7 DAYS** 를 눌러 한 번 갱신합니다.

## 3단계: GFN Rumble 앱 설치 — 아이패드에서

이 앱은 SideStore의 앱 목록(Browse)에는 없습니다. 파일을 받아서 직접 고릅니다.

1. 아이패드 **Safari** 로 아래 주소를 열고, "다운로드하겠습니까?"에서 **다운로드** 를 누릅니다.
   `https://github.com/Lunorsun/gfn-rumble/releases/latest/download/GFNRumble.ipa`
   - 받아지면 Safari 오른쪽 위에 ↓ 아이콘이 생깁니다.
2. LocalDevVPN이 **연결된 상태**인지 확인합니다.
3. SideStore → **My Apps** → 왼쪽 위 **+** → **최근 항목** (또는 iCloud Drive → 다운로드) → `GFNRumble.ipa` 선택.
4. 홈 화면에 **GFN Rumble** 앱이 생깁니다.

## 4단계: 자동 갱신 설정

무료 Apple ID로 설치한 앱은 7일마다 서명을 갱신해야 합니다. SideStore가 이걸 아이패드에서 대신 해 줍니다.

1. **설정 → 일반 → 백그라운드 앱 새로 고침** 에서 SideStore를 켭니다.
2. SideStore의 **Settings** 에서 **Background Refresh** 를 켭니다.
3. LocalDevVPN은 켜 둔 채로 두는 것이 좋습니다. 갱신할 때 VPN이 연결돼 있어야 합니다.

더 확실하게 하려면 '단축어' 앱의 자동화를 씁니다.

- 단축어 앱 → **자동화** → **+** → **특정 시간** (예: 매일 새벽) → **즉시 실행**
- 동작으로 SideStore의 **Refresh All Apps** 를 추가합니다.
- 이 부분은 공식 문서에서 확인하지 못했고, 메뉴 이름이 버전에 따라 다를 수 있습니다. 막히면 화면을 Claude에게 보여주세요.

**자동 갱신이 실패해도 괜찮습니다.** 일주일에 한 번 SideStore를 열어 **My Apps** 의 남은 날짜를 누르면 됩니다. PC는 필요 없습니다.

## 5단계: 사용과 진동 테스트

1. 컨트롤러를 아이패드에 블루투스로 연결합니다. (설정 → Bluetooth)
2. **GFN Rumble** 앱을 열고 지포스 나우에 로그인합니다.
3. 화면 **왼쪽 아래의 흐릿한 톱니바퀴** 를 누르면 메뉴가 나옵니다.

**테스트는 이 순서로 해 주세요.**

| 순서 | 메뉴 | 기대 결과 |
|---|---|---|
| 1 | 진동 테스트 1: 컨트롤러 직접 | 왼쪽이 묵직하게, 이어서 오른쪽이 가볍게 울림 |
| 2 | 진동 테스트 2: 웹페이지 경유 | 양쪽이 함께 울림 (먼저 컨트롤러 버튼을 한 번 눌러 주세요) |
| 3 | 진동이 있는 게임 실행 | 게임 안에서 진동 |

**결과에 따라**

- **1번이 안 울림**: 그 컨트롤러는 아이패드에서 진동을 지원하지 않습니다. 다른 컨트롤러로 해 보세요.
- **1번은 되는데 2번이 안 됨**: 앱의 연결 부분 문제입니다. '상태 보기' 화면을 찍어 Claude에게 보여주세요.
- **1, 2번은 되는데 게임에서 안 울림**: 지포스 나우가 진동 신호를 보내지 않는 경우입니다. 게임을 잠깐 한 뒤 '상태 보기' 화면을 찍어 보여주세요. 이 경우 앱을 고쳐야 합니다.

톱니바퀴가 거슬리면 메뉴의 **이 버튼 숨기기** 를 누르세요. 앱을 다시 켜면 돌아옵니다.

### 설정 (톱니바퀴 → 설정)

- **서명 만료 알림**: 만료 3일 전부터 매일 밤 9시, 마지막 날 3시간·1시간 전, 만료 때 알려 줘요(밤 11시~아침 8시 제외). 서명 파일에서 만료 날짜 하나만 읽어요.
- **진동 세기·최소 세기**, **듀얼센스 방아쇠 효과**(게임과 상관없는 흉내 효과)
- **화면 맞춤**(전체 보이기/꽉 채우기/늘리기), **화질 최대 설정 방법** 안내
- **경고**: 배터리·발열·저전력·연결, 대기열 끝·잠수 경고(앱이 켜져 있을 때)
- **실험 기능**: TV 모드, 스틱 데드존·곡선·반전·A/B 바꾸기, 마우스·키보드, **2K 화질 요청**(기본 꺼짐. NVIDIA 약관 위반으로 계정 정지 위험이 있어요. 2K가 안 되거나 끊김·발열이 생기면 화면에 알려 줘요)

빌드할 때 `scripts/security-check.sh` 가 금지된 코드(인터넷 직접 접속, 로그, 클립보드, 기기 위장 등)를 검사해요.

## 제한 사항

- 무료 Apple ID로는 SideStore를 포함해 **앱 3개까지** 설치할 수 있습니다.
- 이 버전은 **진동만** 추가합니다. 해상도는 Safari와 같습니다.
- 미성년 계정(가족 공유의 자녀 계정)은 앱 서명이 막힐 수 있습니다. 그럴 땐 iloader와 SideStore에 다른 Apple ID를 쓰면 됩니다. 아이패드에 로그인된 계정은 바꾸지 않아도 됩니다.
- iPadOS를 업데이트하거나 초기화하면 SideStore 연결(페어링 파일)이 풀릴 수 있습니다. 그때는 [공식 안내](https://docs.sidestore.io/docs/advanced/pairing-file)를 따라 PC에 한 번 더 연결합니다.
